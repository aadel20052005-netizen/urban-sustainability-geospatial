# 🏙️ Urban Sustainability Geospatial Analysis

An interactive geospatial analysis and visualization project focused on urban sustainability metrics. This project leverages Python, Pandas, and Plotly to analyze geospatial data, evaluate key sustainability indicators across various regions, and present findings through interactive visual charts and maps.

---

## 📌 Features

- **Data Processing & Cleaning**: Automated handling of missing values, spatial coordinates, and metric formatting using `pandas` and `numpy`.
- **Geospatial & Statistical Analysis**: Evaluation of key urban indicators such as green coverage, energy efficiency, waste management, and carbon emissions.
- **Interactive Visualizations**: Dynamic visual insights, scatter maps, and distribution charts powered by `plotly.express` and `plotly.graph_objects`.

---

## 🛠️ Tech Stack & Tools

- **Language**: Python 3.x
- **Data Manipulation**: Pandas, NumPy
- **Data Visualization**: Plotly (Express & Graph Objects)
- **Environment**: Jupyter Notebook / VS Code
